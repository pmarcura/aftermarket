`geist@1.8.2` (`dist/fonts/geist-pixel/GeistPixel-Square.woff2`).

Carregada localmente por `design/identidade.css`; não exige o pacote Geist em
execução. Aplicada a títulos, navegação, ações e valores destacados. Archivo
continua nos textos corridos e nas legendas pequenas para preservar a leitura.
