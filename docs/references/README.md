# Referências visuais originais

Treze imagens fornecidas pelo usuário, preservadas em seus bytes originais. O manifesto registra nome, tamanho e SHA-256. Não são assets públicos do jogo nem comprovam direito de redistribuição fora deste projeto.

| Arquivo                            | Uso                                           |
| ---------------------------------- | --------------------------------------------- |
| `01_mapa_principal.png`            | Composição principal de mapa e painel lateral |
| `02_oportunidades.png`             | Análise regional e comparação                 |
| `03_comprar_propriedade.png`       | Detalhes e confirmação da aquisição           |
| `04_meus_negocios.png`             | Portfólio e tabela de estabelecimentos        |
| `05_producao_industrial.png`       | Receita, insumos e fila                       |
| `06_loja_varejista.png`            | Estoque, varejo e abastecimento               |
| `07_mercado_b2b.png`               | Fornecedores e custo colocado no destino      |
| `08_contratar_frete.png`           | Carga, rota e cotações                        |
| `09_transportadora.png`            | Frota e disponibilidade                       |
| `10_empresa_financas.png`          | Patrimônio e histórico financeiro             |
| `mapa-conceito-original.png`       | Conceito inicial do mapa                      |
| `painel-conceitos-original.png`    | Visão conjunta das interfaces                 |
| `painel-alternativas-original.png` | Composições alternativas                      |

A aplicação desenha componentes reais e usa cartografia interativa. Essas imagens servem exclusivamente para consulta e comparação visual.
